
# 🎯 Number Guessing Challenge

A fun and interactive number guessing game built using HTML, CSS, and JavaScript.

## 🎮 Features

- Three difficulty levels: Easy, Medium, Hard
- Random secret number
- Too High / Too Low hints
- Limited attempts
- Score calculation
- Best score tracking
- Play Again option
- Responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🚀 How to Play

1. Select a difficulty level.
2. Click Start Game.
3. Enter your guessed number.
4. Follow the hints.
5. Guess correctly before attempts run out!
